PURPOSE:

This vocabulary manages technical platform names and resource types.

ACCEPT LIST:

Contains proper names (e.g., ILLiad, Aeon, HathiTrust) and technical library terms (e.g., incunabula, microfilm) that must be accepted as correctly spelled and excluded from complexity warnings.

REJECT LIST:

Used to flag deprecated tool names or retired software platforms to ensure outdated resources are not accidentally mentioned in current web documentation.
