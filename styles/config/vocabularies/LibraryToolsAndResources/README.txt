PURPOSE: Manages technical platform names and resource types.

ACCEPT LIST:

Proper names (e.g., ILLiad, Aeon, HathiTrust) and technical library terms (e.g., incunabula, microfilm) that must be accepted as correctly spelled and excluded from complexity warnings.

REJECT LIST:

Flag deprecated tool names or retired software platforms to ensure outdated resources are not accidentally mentioned in current web documentation.
