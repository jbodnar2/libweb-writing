# Proxy Authorization Request

## [Proxy Authorization Request](https://library.gsu.edu/services-and-spaces/borrowing-services/proxy-authorization-request/)

Faculty can use this form to submit a proxy authorization request to allow another user to checkout Georgia State University library materials and pick up interlibrary loan or GIL Express books on their behalf. Requests for materials must be made by faculty themselves. Under this arrangement, the instructor agrees to be responsible for responding to notices, returning/renewing materials on time, and paying any fees for books that are lost or damaged.
