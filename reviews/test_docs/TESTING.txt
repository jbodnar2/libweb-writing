# Test Docs for Rule Validation

These files are intentionally written with known issues so you can verify that custom rules and configs still work after changes.

## How to Run

- Run one file:
  - ./review.sh test_docs/01-university-style-checks.md
- Run all test docs:
  - for f in reviews/test_docs/*.md; do base="${f#reviews/}"; ./review.sh "$base"; done
