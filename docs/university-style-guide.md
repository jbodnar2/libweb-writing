# University Style Guide: Quick Reference

This guide summarizes the Georgia State University (GSU) standards for web content. Use these rules to ensure institutional consistency.

## 1. University Identity

- **First Reference**: Always use "Georgia State University."
- **Subsequent References**: Use "Georgia State," "the university" (lowercase "u"), or "GSU."
- **Headlines**: Avoid using the abbreviation "GSU" in main page titles.
- **Degrees**:
  - Use "bachelor’s degree" or "master’s degree" (lowercase with apostrophe).
  - Use "associate degree" (lowercase, no apostrophe).
  - Capitalize only specific formal titles: "Bachelor of Arts in English."

## 2. Time & Dates

- **A.M. & P.M.**: Use lowercase with periods: 9 a.m., 4:30 p.m.
- **Top of the Hour**: Do not use ":00."
  - **Yes**: 10 a.m.
  - **No**: 10:00 a.m.
- **Noon & Midnight**: Use these words instead of 12 p.m. or 12 a.m.
- **Date Spans**: Use a hyphen without spaces: Oct. 1-15.

## 3. Punctuation & Formatting

- **Oxford Comma**: Omit the serial comma unless it is needed for clarity.
  - **Example**: books, journals and databases.
- **Ampersands**: Use "and" in body text. Use "&" only for official brand logos.
- **Exclamation Points**: Avoid them. Maintain a professional, neutral tone.
- **Underlining**: Never underline text; it confuses users who expect a link.

## 4. Inclusive Language

- **First-Year Students**: Use "first-year student" instead of "freshman."
- **Gender**: Use the singular "their" for unnamed individuals. Avoid "his or her."
- **Disabilities**: Use person-first language. Avoid "afflicted with" or "victim of."

## 5. Word Usage

- **Health Care**: Use as two words (health care) unless part of a proper noun.
- **Adviser**: Always spell with "-er" (not "advisor").
- **Quantities**: Use "more than" instead of "over" for numbers.
- **Regardless**: Never use "irregardless."
