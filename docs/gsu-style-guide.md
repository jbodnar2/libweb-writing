# GSU Writer's Style Guide

## When to Use This File

- Use this first for university-wide language and writing conventions.
- Use this when reports flag time/date, punctuation, inclusive language, and web mechanics checks.
- Use this as baseline policy when a generic lint rule conflicts with local project intent.

See the full [Writer's Style Guide](https://commkit.gsu.edu/writers-style-guide/) for full documentation.

## 1. University Identity & Names

- Primary Reference: Use "Georgia State University" on the first mention.
- Secondary Reference: Use "Georgia State", "GSU", or "the university" (lowercase "u").
- Headlines: Avoid using the abbreviation "GSU" in page titles or main headlines.
- Degrees: Capitalize official degree names (_Bachelor of Arts in English_). Lowercase general references (_a master’s degree_).

## 2. Time & Date Formatting

- A.M. & P.M.: Always use lowercase letters with periods (a.m. and p.m.).
- The ":00" Rule: Do not include minutes for top-of-the-hour times. Use 9 a.m., not 9:00 a.m.
- Noon & Midnight: Use these words instead of 12 p.m. or 12 a.m.
- Time Zones: Place the abbreviation immediately after the time (10 a.m. EST). No commas needed.
- Date Spans: Use an en dash (–) or a hyphen without spaces: Oct. 1–15.

## 3. Punctuation & Typography

- Oxford Comma: GSU generally omits the serial comma (e.g., _red, white and blue_).
- Exclamation Points: Avoid them. Use professional, neutral tones.
- Ampersands: Use "and" in body text. Only use "&" if it is part of an official logo or brand name.
- Underlining: Never underline text for emphasis; users expect underlined text to be a clickable link. Use bold instead.
- All Caps: Do not use all-capital letters for emphasis.

## 4. Inclusive Language & Student References

- First-Year Students: Always use first-year instead of "freshman."
- Class Levels: Avoid "upperclassman" or "underclassman."
- Rankings: Use the abbreviation No. before a number (e.g., _Ranked No. 1 in the nation_). Do not use the pound sign (#).

## 5. Web & Technical Mechanics

- Links: Use descriptive text (e.g., [View the 2026 Academic Calendar]). Never use "click here" or "read more."
- Login vs. Log in: \* Login (Noun/Adj): "Enter your login credentials."
  - Log in (Verb): "Please log in to the portal."
- Email: One word, no hyphen.
- Website: One word, lowercase, unless starting a sentence.

## 6. Tone & Structure

- Active Voice: Use direct, action-oriented verbs.
- The "You" Perspective: Speak directly to the reader using "you" and "your." Refer to the institution as "we" or "our."
- Inverted Pyramid: Put the most important "who, what, where, and why" in the first paragraph.
- Scannability: Use short paragraphs and bulleted lists. Avoid "Welcome" messages or fluff introductions.
